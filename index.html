关于我

把想法写成代码，把坚持跑成习惯

我是 丁卓，上海师范大学计算机专业的学生。对我来说，编程最有意思的地方在于 「用确定的逻辑解决不确定的问题」——从一段跑不通的代码到顺畅运行的瞬间，是这个专业给我的最大快乐。

学习路径上，我从 C 语言入门，理解了内存与指针的底层逻辑；随后用 Java 建立起面向对象的思维方式，用 C++ 感受性能与抽象的平衡； 再用 MySQL 把数据真正落下来。四门语言/技术互相印证，让我既有底层的耐心，也有工程的视角。

课业之外，我是跑道上的人。中长跑教会我的不是速度，而是节奏与配速感—— 知道什么时候该冲，什么时候该稳。这种能力同样适用于写代码：不追求一次写完，只追求每天都往前一点。
